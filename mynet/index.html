MyNet
A fully independent, lightweight, and secure HTTPS replacement.

Modern networking,
stripped to the essentials.

MNET/1.0 over TLS — minimal text protocol, built-in Markdown rendering, and a standalone GUI browser.
Zero dependencies beyond the Python standard library.

Get started →

Zero Dependencies

Built solely on Python's ssl and socket. No external packages.

Markdown Native

Replaces HTML with clean, modern Markdown. Render tables, lists, code, and more.

Standalone Browser

Feature-rich GUI client with tabs, bookmarks, dark/light themes, and API tester.

TLS & Security

Automatic certificate generation, rate limiting, CORS, and secure security headers.

Lightweight

Header size ~50 bytes vs 300+ in HTTP/2. Minimal overhead, maximum speed.

Feature Rich

LRU cache, gzip compression, WebSocket support, file uploads, and JSON APIs.

Why MNET?

HTTPS is heavy and complex. MNET/1.0 is lean, transparent, and powerful.

# If it can be smaller, make it smaller. # If it can be simpler, make it simpler. # If it doesn't need a dependency, remove it.

$ mnet vs https ───────────────────────────────────────── ▸ Header size: ~50 bytes vs 300+ bytes ▸ Dependencies: ssl/socket vs OpenSSL + HTTP libs ▸ Protocol line: MNET/1.0 vs GET / HTTP/1.1 ▸ Lines of code: ~200 vs Thousands

Quick Start

Run your own MyNet server and browser in seconds.

$ ./run_server.sh # or: python3 -m mynet mynet index.md $ ./run_browser.sh # or: python3 browser.py $ open mynet://localhost:7443/
